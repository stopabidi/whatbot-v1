## How to Use This Guide

1. Send each message to the WhatsApp number
2. Wait for the response
3. Mark ✅ (pass) or ❌ (fail) in the Status column
4. If failed, note what went wrong in the Notes column
5. At the end, report results

**WhatsApp number:** Check `.env` for `TWILIO_WHATSAPP_NUMBER`
